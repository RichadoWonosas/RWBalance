# 界面样式开发规范

## 默认实现方式

1. 新增或修改界面时，布局、间距、尺寸、排版、边框、圆角、颜色、阴影、交互状态和响应式变化默认使用 Tailwind CSS 工具类。
2. 响应式样式以移动端为基础，再用 `compact:`、`settings:`、`mobile:`、`desktop:`、`wide:` 增强；禁止新增裸像素断点或 `width < ...` 的桌面优先覆盖。
3. 颜色必须使用 `tailwind-theme.css` 注册的 `app-*` 语义令牌，或使用 `--rw-*` 运行时变量；不得把动态主题色硬编码到页面组件。
4. 动态色相、图表尺寸、标签树深度等运行时值使用 Vue `style` 绑定或 Tailwind 任意值语法。

## 复用边界

- Modal 使用 `AppModal.vue`；选择器使用现有 Picker、Tag、Account 组件。
- Button、Surface、Field、Pill、Tag 的共享视觉规则集中在 `ui.css` 的有限 `@layer components` 中，页面不得复制另一套完整规则。
- 页面组件只负责组合业务内容。新页面不得重新塞回 `App.vue`，大型向导或多步骤表单应拆成独立组件。

## 原生 CSS 保留范围

原生 CSS 仅用于：主题变量与运行时桥接、全局基础行为、关键帧和低动画策略、复杂伪元素、浏览器实验特性、SVG 深层选择器，以及无法用单组工具类清晰表达的跨元素状态。保留规则必须放在对应职责文件中：

- `theme.css`：`--rw-*` 主题变量和明暗模式；
- `effects.css`：复杂伪元素和视觉效果；
- `motion.css`：关键帧、过渡及 reduced-motion；
- `native-controls.css`：原生控件实验特性；
- `ui.css`：`@layer base` 与有限共享组件层；
- `main.css`：只维护导入顺序。

## 提交前检查

运行 `npm run build`、`npm test` 和与变更页面对应的 Playwright 用例。涉及断点、折叠、固定底栏、弹窗或数据表时，必须包含布局回归；新增 CSS 变量必须使用 `--rw-*`，并通过样式静态审计。
